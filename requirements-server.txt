# This deliberately excludes PySide6 and the other desktop-GUI-only
# dependencies in requirements.txt - the API container never renders a
# desktop UI, and PySide6 alone drags in a full Qt/X11 dependency chain
# that has no purpose in a headless server image (larger image, longer
# builds, more CVE surface to track for no benefit).
#
# Keep version pins in sync with requirements.txt for anything both files
# list - they must stay compatible since both install into the same
# codebase.
