# API Reference

Full interactive documentation is auto-generated by FastAPI at
`http://localhost:8000/docs` (Swagger UI) and `/redoc` when the API is
running. This page summarizes the endpoints. See `docs/SECURITY.md` for
the full role/permission matrix.

Base URL: `http://localhost:8000`

## Authentication

### `POST /api/auth/users`

One-time bootstrap only: works exclusively when the `users` table is
empty, and always forces the new account to the `admin` role regardless of
the `role` field sent. Returns 403 once any user exists - use
`POST /api/auth/admin/users` (or `scripts/create_admin.py`) after that.

```json
{ "username": "admin", "password": "A-Strong-Passw0rd!", "full_name": "Jane Doe", "role": "admin" }
```

Password policy: 12+ characters, upper/lower/digit/special character.

### `POST /api/auth/admin/users` (requires admin)

Creates any subsequent user. Same body shape as above.

### `POST /api/auth/token`

OAuth2 password grant. Form-encoded `username` + `password`. Rate-limited
(`OAP_RATE_LIMIT_LOGIN`, default 5/minute). Returns `423 Locked` if the
account is in lockout after repeated failed attempts.

```json
{ "access_token": "...", "token_type": "bearer", "mfa_required": false, "pending_token": null }
```

If the account has MFA enabled, `access_token` is `null` and
`mfa_required` is `true` instead - exchange `pending_token` via
`POST /api/auth/mfa/verify` (below) for a real token.

Pass the token as `Authorization: Bearer <token>` on every other request.

### `POST /api/auth/mfa/setup` (authenticated)

Begins MFA enrollment for the calling user. Requires `OAP_ENCRYPTION_KEY`
to be configured server-side (500 error otherwise). Returns:

```json
{ "secret": "...", "otpauth_uri": "otpauth://totp/...", "recovery_codes": ["...", "... (10 total)"] }
```

Recovery codes are shown only this once.

### `POST /api/auth/mfa/confirm` (authenticated)

```json
{ "code": "123456" }
```

Verifies the first code from the authenticator app and enables MFA for
the account.

### `POST /api/auth/mfa/verify`

```json
{ "pending_token": "...", "code": "123456" }
```

`code` may be a 6-digit TOTP code or a one-time recovery code. Returns a
normal `TokenResponse` with a usable `access_token` on success.

### `POST /api/auth/mfa/disable` (authenticated)

```json
{ "password": "current-password" }
```

### `POST /api/auth/admin/users/{username}/mfa/reset` (requires admin)

Force-disables MFA for another user (lost-device recovery). Audit logged.

## Documents

### `POST /api/documents/upload` (requires editor)

Multipart file upload (`file` field). Validates extension, size, and
magic-byte content before saving under a randomly generated filename in
`local_import_root`. Returns `{"stored_path": "...", "original_filename": "..."}`.

### `GET /api/documents`

Query params: `skip` (≥0), `limit` (1-200, default 50). Excludes
soft-deleted documents. Returns a list of `DocumentOut`.

### `GET /api/documents/{document_id}`

Returns a single document's full metadata (including `approval_status`,
`reviewed_by`, `reviewed_at`), or 404 if missing or soft-deleted.

### `GET /api/documents/{document_id}/versions`

Returns the document's full version history (`DocumentVersionOut[]`),
newest last, each with a SHA-256 checksum of the file at that point.

### `POST /api/documents/{document_id}/approve` (requires reviewer)
### `POST /api/documents/{document_id}/reject` (requires reviewer)

```json
{ "notes": "Optional review notes" }
```

### `POST /api/documents/{document_id}/rollback` (requires editor)

```json
{ "version_id": "..." }
```

Copies the named version's file forward as a new version and points
`output_path` at it. The target version's file is never modified.

### `DELETE /api/documents/{document_id}` (requires admin)

Soft delete only - the row, processing history, and files are retained
but excluded from listing/search. There is no hard-delete endpoint.

## Search

### `GET /api/search`

Query params (all optional): `estate`, `district`, `workflow_name`,
`document_type`, `date_from`, `date_to`, `keyword`, `ocr_text`,
`politician`, `reference_number`, `filename`, `limit` (1-200), `offset`.

Returns `{ "total": int, "results": [DocumentOut, ...] }`.

## Workflows

### `GET /api/workflows`

Lists every workflow defined under `config/workflows/`, with its plugin id
and stage order.

### `POST /api/workflows/run` (requires editor)

```json
{
  "workflow_name": "housing_estate_poster",
  "document_paths": ["poster.png", "application.pdf"],
  "triggered_by": "jane.doe"
}
```

Each path is resolved and must fall under an approved import/archive/export
root (`app.workflow.runner.allowed_import_roots`) - anything else is
rejected per-document with a clear reason, not a server error. Runs each
document through the named workflow synchronously and persists a
`Document` + `ProcessingEvent` + `DocumentVersion` row per document.
Returns per-document success/failure, halt reason (if any), output path,
and extracted fields.

## Plugins

### `GET /api/plugins`

Lists currently enabled, successfully loaded plugins with id, display name
and version.

## Settings (requires admin)

### `GET /api/settings`

Returns all admin-configurable runtime settings, e.g.
`{"allow_cloud_ai": "false", "ai_usage_logging_enabled": "true", "data_retention_days": "365"}`.

### `PUT /api/settings`

```json
{ "key": "allow_cloud_ai", "value": "true" }
```

Takes effect immediately (no restart) - see `docs/PRIVACY.md`.

## Error format

FastAPI's standard `{"detail": "..."}` shape is used for all 4xx/5xx
responses. Unhandled server errors always return a generic 500 message
(the real error is logged server-side, never returned to the client).
Workflow-level failures are not HTTP errors — they come back as
`success: false` entries in `/api/workflows/run`'s response with a
human-readable `halt_reason`, since a single bad document should not fail
the whole batch request.
